# 📚 StudyMate AI

An AI-powered learning assistant that helps students summarize notes, generate quizzes, and understand concepts using Large Language Models (LLMs).

## 🚀 Features

- 📝 AI Note Summarizer
- ❓ AI Quiz Generator
- 💬 AI Study Chatbot
- 📚 Concept Explainer

## 🛠 Tech Stack

### Frontend
- Next.js
- Tailwind CSS

### Backend
- FastAPI

### AI
- OpenAI API

### Deployment
- Docker
- AWS App Runner
